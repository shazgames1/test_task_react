# GitHub Repository Search App

Это приложение было разработано как тестовое задание для собеседования на позицию web-разработчика (react). Приложение позволяет осуществлять поиск репозиториев на GitHub с использованием GitHub REST API и предоставляет результаты поиска в удобной таблице.

Вы можете протестировать приложение по следующей [ссылке](https://test-task-react-six.vercel.app).


## Функционал

- Поиск репозиториев
- Отображение более подробной информации о репозитории
- Пагинация
- Сортировка по числу звёзд, числу форков и дате последнего обновления
- Стилизация с помощью Sass и CSS Modules для стилизации компонентов. Библиотека MUI используется для создания пользовательского интерфейса
- Загрузка данных из API с помощью  используется Redux Toolkit
- Поддержка авторизации запросов с использованием GitHub токена


## Авторизация запросов с использованием персонального токена GitHub

При ограничении доступа со стороны GitHub можно указать персональный токен GitHub в файле `.env.local` (переменная `GITHUB_TOKEN`), чтобы использовать его при обращении к API GitHub.


## Запуск локально

### 1. Клонирование репозитория

```bash
git clone https://github.com/shazgames1/test_task_react.git
cd test_task_react
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения (опционально)

Создайте файл .env.local в корневой директории проекта и добавьте в него переменную GITHUB_TOKEN, если у вас есть персональный токен GitHub:

```bash
GITHUB_TOKEN=ваш_персональный_github_токен
```

### 4. Запуск приложения

```bash
npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).
